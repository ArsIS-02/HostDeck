Сюда можно положить собственные значки операционных систем (SVG или PNG):

  apple.svg  — для macOS-хостов
  tux.svg    — для Linux-хостов

Если файла нет, интерфейс показывает обычный значок устройства. Логотипы в HostDeck не входят:
берите их с официальных страниц производителей (Apple, Linux Foundation) и соблюдайте условия использования.
Подойдёт и PNG: тогда назовите файлы apple.png и tux.png.
